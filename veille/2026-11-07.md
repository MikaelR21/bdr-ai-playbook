## Bon usage du jour

**Lis le README avant d'installer, et repère ce qui coûte.** Beaucoup de packs "GTM" sont des vitrines : les skills sont gratuits mais appellent un service payant (crédits, abonnement, serveur MCP de l'éditeur). Avant d'installer, cherche dans le README les mots "API key", "credits", "MCP", "trial". Si le skill ne marche qu'avec leur outil, ce n'est pas un skill, c'est une démo commerciale.
